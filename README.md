# ThreatGuard

Real-Time AI Digital Threat Intelligence Platform

ThreatGuard is an end-to-end AI/ML cybersecurity application for detecting phishing URLs and scam messages, generating interpretable risk scores, and presenting threat intelligence through an interactive web dashboard.

## Planned Capabilities

- Phishing URL detection
- Scam / smishing SMS detection
- QR-code URL extraction
- Explainable AI risk scoring
- FastAPI inference backend
- React security dashboard
- PostgreSQL analysis history
- Model evaluation and monitoring
- Dockerized application

## Architecture

URL / SMS / QR -> Threat Detection Models -> Risk Scoring -> FastAPI -> PostgreSQL -> React Dashboard
